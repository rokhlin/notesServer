# Server Documentation (`docs/`)

This directory contains context files, specifications, API schemas, and service architecture documentation for `notesServer`.

## Purpose
- Provide contextual background for AI agents, skills, and rules during task planning and execution.
- Maintain up-to-date specifications for REST/WebSocket API endpoints, serialization formats, data persistence, and security.

## Structure and Usage
- **API Specifications**: Document routes, request/response models, and status codes.
- **Architecture & Database**: Document data persistence patterns, business logic layers, and integrations.
- **All files must be written in English.**
